# SIMOT AI OS Runtime

Serverless runtime package for SIMOT-MASTER and bounded Workers.

## Current phase
Runtime foundation package prepared for Cloudflare Workers + D1 + Queues.

## Security
Secrets are runtime environment variables/secrets only. Never commit API keys, bot tokens, or Cloudflare credentials.

## Runtime states
FULL / DEGRADED / MANUAL. PAID is prohibited by default.
